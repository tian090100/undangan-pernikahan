# Undangan Lizwan dan Naomi

Versi klien menggunakan tema Premium Batak DAPRITA.

- Halaman utama: `index.html`
- Parameter nama tamu: `?to=Nama%20Tamu`
- RSVP diteruskan ke WhatsApp Naomi.
- Musik diputar dari video YouTube pilihan klien dan memerlukan koneksi internet.
- Empat foto klien tersimpan di folder `assets`.

## Catatan sebelum publikasi

Data final belum disetujui pada bagian checklist formulir. Pastikan klien memeriksa kembali nama orang tua, tanggal, waktu, lokasi, tautan Maps, nomor rekening, izin foto, lagu, dan izin portofolio sebelum tautan dibagikan.
